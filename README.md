# 2026 国庆冰岛攻略

这是一个纯静态网页攻略，入口文件是 `index.html`。

## 本地预览

```bash
python3 -m http.server 4203
```

打开：

```text
http://127.0.0.1:4203/
```

## 长期分享给朋友

推荐使用 GitHub Pages：

1. 在 GitHub 新建一个公开仓库，例如 `iceland-2026-guide`。
2. 上传本文件夹内全部网站文件，包括 `ref32-patch.js`、`offline.js`、`sw.js`、`offline-assets.js`、`travel-backup.html` 和 `assets/`；不要漏掉最终行程补丁或离线文件。
3. 进入仓库 `Settings` → `Pages`。
4. `Source` 选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/root`。
6. 保存后等待 1-2 分钟，GitHub 会生成一个长期网址。

## 更新和验证

每次修改行程、页面、样式、脚本或照片后，先运行：

```bash
node scripts/build-offline.cjs
node scripts/test-offline.cjs
```

构建会从最终生效的行程生成 `travel-backup.html`，再生成离线资源清单和版本。两份生成文件必须和源码一起提交。不要手动编辑生成文件。

发布前用本地浏览器确认：四组行程正确、保存照片成功、模拟断网后刷新仍能使用、文字版独立可读。发布后确认 GitHub Pages 部署对应提交成功，并检查线上版本。

已保存行程的浏览器在联网后会检查更新；有更新时点击“有新行程，更新并刷新”。只有核心文件完整并通过内容校验的新版本才可启用，更新时所有已打开的本站页面会刷新；仅更新文字行程时，已保存的照片继续保留。

## 出行前准备

在实际使用的手机和浏览器打开网站，点击“保存离线行程和照片”，另外下载文字备用版到手机“文件”，再开飞行模式验证。离线缓存属于当前浏览器，无痕模式、清理缓存或系统回收存储可能使其丢失；独立文字文件可作为第二份备份。票据、保险救援电话也应单独保存。

外部地图、天气预警与实时路况仍需网络。所有时刻按当地时间，未确认的车次、站点和住宿以订单为准。应急号码及安全入口在页面“离线与应急”中，文字备用版也包含这些信息。

本站为公开静态网页，角色选择不是权限控制。搜索引擎不收录标记只是一项请求，无法让内容变成私密资料；不要提交护照、密码、完整订单号或私人紧急联系人。
